This repository contains a simple card matching game developed in C# using Windows Forms.

A straightforward implementation of a classic card matching game. The game likely involves a grid of cards that are flipped over, and the player tries to find matching pairs. The code appears to be a standard Windows Forms application, suggesting a graphical user interface (GUI) for gameplay.

- **Language:** C#

## Installation

This project is a Windows Forms application. To run it, you will need:

1.  **Visual Studio:** Install Visual Studio (Community Edition is free) from the [official Visual Studio website](https://visualstudio.microsoft.com/downloads/).
2.  **.NET Framework:** Ensure you have the .NET Framework installed (usually comes with Visual Studio).

**Steps:**

1.  Clone this repository to your local machine:
    ```bash
    git clone https://github.com/Thomas1255/card-matching-game.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd card-matching-game
    ```
3.  Open the solution file `FinalLab.sln` in Visual Studio.
4.  Build the project (Build > Build Solution).
5.  Run the project (Debug > Start Debugging or press F5).

*Note: The `App.config` file contains basic configuration, but no external dependencies were detected that require special installation steps beyond having Visual Studio and the .NET Framework.
